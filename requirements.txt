# ── LLM clients ───────────────────────────────────────────────────────────────
# Needed whenever this process owns its LLM: the plain-Python entry point and
# the MCP server with MCP_LLM_MODE=standalone. Both imports are deferred to the

# <81: setuptools 81 removed the bundled pkg_resources.
